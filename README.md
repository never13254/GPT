# Mini Battle Royale

This repository contains a simple top-down "battle royale" style mini-game built with Pygame. One human player fights against nine AI bots on a 2D map.

## Features
- Seven unique weapons: submachine gun, shotgun, assault rifle, pistol, machete, light machine gun and sniper rifle.
- Weapon effects: sniper rifle increases vision; light machine gun and sniper rifle reduce movement speed.
- Armor levels 1–3 providing protection, durability and inventory capacity.
- Healing items: small and large medkits.
- Throwables: grenades (3 second fuse), smoke grenades and molotovs.
- Heavy and light ammunition types.

## Controls
- **WASD** – Move
- **Mouse** – Aim
- **Space** – Shoot
- **1 / 2** – Use small / large medkit
- **G** – Throw grenade
- **H** – Throw smoke grenade
- **J** – Throw molotov

## Running
Ensure `pygame` is installed and run:
```bash
python main.py
```
